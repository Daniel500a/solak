# Examples

This directory contains example usage of the Region Finder tool.

## Files

- `example.py` - Demonstration script that creates sample images and finds regions
- `minimap.jpg` - Sample minimap image (generated by example.py)
- `view.jpg` - Sample view image extracted from the minimap (generated by example.py)
- `result.jpg` - Visualization showing the matched region (generated by example.py)

## Running the Example

```bash
python examples/example.py
```

This will:
1. Create sample minimap and view images
2. Use RegionFinder to locate the view within the minimap
3. Display the results with confidence and position
4. Generate a visualization showing the match

## Expected Output

The example should find an exact match with ~100% confidence, demonstrating how the tool works when given a view that exists within the minimap.
